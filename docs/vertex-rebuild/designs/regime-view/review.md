| 4 | Dealer Gamma | Upstream `regime` uses `"dampened"`/`"amplified"`; missing `row.status === "ok"` check; dual staleness limits can contradict single `ageSeconds`/`staleLimitSeconds`. | **PROPOSE FIX (applied)** — Require `row.status === "ok"`; map `"dampened"`/`"positive"` and `"amplified"`/`"negative"`; resolve `asOf = gex.asOf ?? gex.oiSession ?? generatedAt`; check `oiSession` against 96 h; report the actual breached limit (`900 s` push vs `345,600 s` upstream) so `ageSeconds` and `staleLimitSeconds` match `stale`. |
