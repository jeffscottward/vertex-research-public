# Design Review Resolution Record

Fresh-context design review run on 2026-11-22 against `docs/vertex-rebuild/designs/option-chain-store/design.md` and the repository codebase. All 15 findings were accepted and resolved in `design.md`, `before-after.svg`, and the implementation.

| # | Severity | Finding | Resolution |
| --- | --- | --- | --- |
| 1 | Critical | `handler.ts` `agentApiKeyScopeInterceptor` would block `optionsChain.ingestSnapshot` and `optionsChain.snapshot` unless listed in `AGENT_API_KEY_PROCEDURE_PATHS` | Added all four procedures (`optionsChain.expiries`, `optionsChain.chain`, `optionsChain.ingestSnapshot`, `optionsChain.snapshot`) to `AGENT_API_KEY_PROCEDURE_PATHS` and updated the 403 message and `agent-api-keys.test.ts`; kept `optionsChain.ingestSnapshot` out of `AGENT_API_KEY_READ_PROCEDURES`. |
| 2 | Critical | `options-chain-ibkr.ts` quotes only 12 ATM strikes and mixing live IBKR with 15-min delayed Yahoo inside `measure()` biases skew slopes and breaks `golive/generator.py` (`yahoo_delayed_snapshot` & full strike ladder) | Keep local CSV + `summary.json` calibration mirror on single-timestamp Yahoo `yfinance` (preserving `calibrate.py` and `golive/generator.py`), and overlay IBKR live quotes from `optionsChain.chain` onto the Postgres ingest payload while Yahoo fills every gap. |
| 3 | Critical | `remeasure()` globs all CSVs and would include near-month (<30 DTE) and LEAPS expiries in `summary["symbols"]`, distorting `calibrate.py` | Filter CSV expiries in `remeasure()` through `monthly_expiries(found, today)` (`DTE_RANGE = (30, 75)`) for `summary["symbols"]` and record all stored expiries in `summary["storedExpiries"]`. |
| 4 | Major | SPY market-open probe (`MAX_TRADE_AGE_MIN = 45`) could behave ambiguously with `optionsChain.chain` | Keep SPY market-open probe on `yfinance` `last_trade` over SPY's monthly chains. |
| 5 | Major | Upsert on `(snapshot_at, underlying, expiry)` should return the actual DB row `id` before replacing child quotes | Use `.returning({ id: optionChainSnapshots.id })` from `onConflictDoUpdate` inside the transaction before deleting and re-inserting `option_chain_snapshot_quotes`. |
| 6 | Major | Zod `int()` allows values above Postgres `int32`, unbounded `iv`, and drifted `tradingDay` | Bound `volume`/`openInterest` to `0..2_147_483_647`, bound `iv` to `0..100`, validate `tradingDay` within ±1 calendar day of `snapshotAt`, and enforce `< 'Infinity'::float8` in SQL CHECKs. |
| 7 | Major | `--backfill` pandas float-int CSV strings (`"12.0"`, `"NaN"`) and quote provenance mapping | Parse integer CSV fields via finite-float conversion (`int(round(float(text)))`), and define deterministic `quote_source_of()` mapping to `'ibkr' \| 'yahoo' \| 'quantdata' \| 'mixed'`. |
| 8 | Major | HTTP client needs mandatory `Origin` header on `/api/orpc` POST, response size cap, and payload under 1 MiB | Send `Origin` header matching base URL, enforce 8 MiB response cap and 20s timeout, cap ingest batch at 4000 quotes (< 1 MiB JSON), refuse redirects and non-loopback HTTP, scrub API key. |
| 9 | Major | `optionsChain.snapshot` response caps, empty-state semantics, and `snapshotAt`/`tradingDay` precedence | Explicit Zod caps (`availableDays` ≤ 400, `availableSnapshots` ≤ 60, `expiries` ≤ 20, `quotes` ≤ 4000), truthful empty 200 response when no snapshot matches, combined filter semantics when both `snapshotAt` and `tradingDay` are passed. |
| 10 | Major | `vertex-option-chain-run` `OPTION_CHAIN_PUSH` behavior, `units.test.ts` compatibility, and push-failure exit code | Load key when `VERTEX_ORIGIN` and key file exist unless `OPTION_CHAIN_PUSH=0`; warn if `OPTION_CHAIN_PUSH=1` without config; keep offline args compatible with `units.test.ts`; exit 1 on ingest push failure while preserving local CSVs. |
| 11 | Minor | `(underlying, trading_day)` index did not cover `snapshot_at` ordering | Upgraded index to `(underlying, trading_day, snapshot_at)`. |
| 12 | Minor | Rollback must drop child table before parent table | Verified `option_chain_snapshot_quotes` is dropped before `option_chain_snapshots` in `0092_option_chain_snapshots.down.sql`. |
| 13 | Minor | Calling `optionsChain.expiries` would trigger 7 extra IBKR snapshot waves | Discover expiries from `ticker.options` (`yfinance`) and call `optionsChain.chain(symbol, expiry)` only for the selected target expiries (20s timeout, immediate Yahoo fallback). |
| 14 | Minor | Acceptance checks missed `verify:prepush`, `openapi:check`, `public-names`, and `Agent review:` | Added all repository CI/merge gates to `design.md`. |
| 15 | Minor | `before-after.svg` said `"3 ALWAYS"` instead of `"UP TO 3"` | Updated SVG labels to `"UP TO 3"` and `"2–3 / sym"`. |
